# Notebooks

This folders should hold Jupyter Notebooks (`.ipynb`) used for generating figures and exploring results interactively.

These should be limited to **read** the files generated in `../plots/` or to import functions from `../src/visualization.py` for visualization.
1. AIC and BIC order selection curves (`mvar_order_selection_*.json`).
2. Condition and group contrast heatmaps (`t_values_*`, `p_values_*`).
3. 3D HTML plots.
4. Spectral power sanity check (`power_contrast_*.npz`).
